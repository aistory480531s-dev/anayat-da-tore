# ANAYAT DA STORE — HTML/CSS/JavaScript Edition

## Files
- index.html — customer store
- admin.html — admin dashboard
- style.css — complete styling
- app.js — login, signup, products, cart, checkout, orders and WhatsApp
- admin.js — admin orders/products

## Run
Simply double-click `index.html`, or open it with a browser.

For best results use VS Code + Live Server, but no Node.js/backend is required.

## Customer
1. Sign Up
2. Browse products
3. Add to cart
4. Checkout
5. Order is saved in browser localStorage
6. "Send Order on WhatsApp" opens WhatsApp with order details
